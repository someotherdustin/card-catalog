# ADR index

Generated by the card-catalog plugin from the ADRs in this directory. Edits here are overwritten.
One line per ADR: `label [status] amended | title | summary`. Search it with grep, then open the ADRs that match.

- [ADR-0001](0001-generalize-to-record-collections.md) [accepted] 2026-10-01 | Generalize from ADRs to record collections, for agents and operators alike | We'll generalize card-catalog from ADRs to any collection of markdown records, described by per-type profiles and an optional repo config, with one core shared by hooks, a CLI and helper skills and agents. Principle: the best way is whatever works for you, agent or operator.
- [ADR-0002](0002-never-index-ignored-paths.md) [accepted] 2026-10-01 | Never index ignored paths; indexes depend only on committed files | Records under paths that git or a committed agent ignore file hides are never indexed, even if config lists them, since an index would leak their titles and summaries to agents. Indexes depend only on committed files, so every writer builds the same one.
